Веб-типографика и шрифты в CSS

Урок 12 WEB-дизайн

Почему важны шрифты?

Шрифты помогают сделать сайт понятным и удобным для чтения. Для заголовков используется Montserrat, а для обычного текста Inter.

Размер и интервалы

Для текста используется размер 1rem. Заголовки имеют больший размер. Межстрочный интервал равен 1.6.

Цитата

Хорошая типографика делает текст простым и удобным для чтения.
